## 🇬🇧 English Version

**InnoElectrica Expo 2026** is a comprehensive competition management platform built with Laravel and Filament. It is designed to handle the entire lifecycle of an event, from participant registration and team management to multi-role administration, submission tracking, and automated judge scoring with dynamic criteria.

### 🌟 Key Features
- **Dynamic Landing Page:** Real-time Gallery, Sponsors, and Media Partners powered by an intuitive admin panel.
- **Unified Authentication:** Beautiful, glowing dark-theme UI for participant login and registration.
- **Multi-Role Architecture:** 
  - **Super Admin & Moderator:** Full control over competitions, verifications, and user management.
  - **Judge:** Dedicated scoring dashboard with dynamic assessment criteria and weighted scoring.
  - **Participant:** Personalized dashboard to manage team members, submit work, and track registration status.
- **Advanced Competition Logic:** Support for Solo and Team modes, dynamic max-member limits, and automated PDF/CSV report generation.
- **Smart Optimization:** Automatic on-the-fly `.webp` conversion for all uploaded administrative images using native PHP GD.

## 🇮🇩 Versi Bahasa Indonesia

**InnoElectrica Expo 2026** adalah platform manajemen kompetisi komprehensif yang dibangun menggunakan Laravel dan Filament. Sistem ini dirancang untuk menangani seluruh siklus acara, mulai dari pendaftaran peserta dan manajemen tim, hingga administrasi multi-peran, pelacakan pengumpulan karya, dan penilaian otomatis oleh juri dengan kriteria yang dinamis.

### 🌟 Fitur Utama
- **Landing Page Dinamis:** Galeri, Sponsor, dan Media Partner yang terintegrasi secara real-time dengan panel admin.
- **Autentikasi Terpadu:** UI tema gelap dengan efek *glowing* yang indah dan konsisten untuk login dan registrasi peserta.
- **Arsitektur Multi-Peran:** 
  - **Super Admin & Moderator:** Kendali penuh atas kompetisi, verifikasi pembayaran, dan manajemen pengguna.
  - **Juri (Judge):** Dashboard khusus untuk memberikan nilai dengan kriteria penilaian dan bobot yang dinamis.
  - **Peserta (Participant):** Dashboard personal untuk mengelola anggota tim, mengumpulkan karya, dan melacak status pendaftaran.
- **Logika Kompetisi Tingkat Lanjut:** Mendukung mode Individu dan Tim, batas maksimal anggota dinamis, serta pembuatan laporan PDF/CSV otomatis.
- **Optimasi Cerdas:** Konversi otomatis ke format `.webp` untuk semua gambar yang diunggah oleh admin menggunakan PHP GD bawaan agar performa website tetap maksimal.
